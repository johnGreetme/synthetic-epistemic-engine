# Security Policy

## Supported Versions

Security updates and patches are actively applied to the following versions of the **Synthetic Epistemic Engine (SEE)**:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

The Kytin Swarm security team takes security and cryptographic integrity very seriously. If you discover a vulnerability, especially related to:
- **Ed25519 Enclave Signing / Verification Bypasses**
- **State-Locked Protocol (SLP) Invariant Violations**
- **Z3 Crucible SAT/UNSAT Proof Poisoning**
- **Tombstone Protocol / Apoptosis Evasion**

**Please DO NOT open a public GitHub issue.**

### Responsible Disclosure Process
1. **Email Details**: Send a detailed security report to [johngreetme@gmail.com](mailto:johngreetme@gmail.com) with the subject prefix `[SECURITY VULNERABILITY] SEE`.
2. **Include Proof-of-Concept**: Provide clear reproduction steps, affected environment, and impact analysis.
3. **Response Timeframe**:
   - **Initial Acknowledgement**: Within 24 hours.
   - **Triage & Status Assessment**: Within 48 hours.
   - **Remediation & Patch Deployment**: Prioritized and coordinated with the reporter before public disclosure.

We appreciate your cooperation in responsible vulnerability disclosure.
